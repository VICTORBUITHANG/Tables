# Clean and Prepare Data for Analysis with Python

This folder contains the same course in two runnable formats and a compiled study guide.

## Course files

- `Python_Clean_Prepare_Data_Course.py` runs the full workflow as a Python script.
- `Python_Clean_Prepare_Data_Course.ipynb` provides an interactive lesson with practice cells and solutions.
- `Python_Clean_Prepare_Data_Study_Guide.tex` is the editable LaTeX source.
- `Python_Clean_Prepare_Data_Study_Guide.pdf` is the compiled study guide.
- `output/` contains the prepared example data, a quality audit, and two figures.
